# @dukelib/sheets

Excel file library for Node.js, powered by Rust.

Form controls are available through `worksheet.formControls`,
`worksheet.formControlCount`, `addFormControl`, `setFormControl`, and
`removeFormControl`. See the repository README for a typed example.

```bash
npm install @dukelib/sheets
```

See [github.com/guseggert/duke-sheets](https://github.com/guseggert/duke-sheets).
